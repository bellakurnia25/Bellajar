TEMPAT GAMBAR DEKORATIF BELLAJAR
================================
Taruh gambar di folder ini dengan nama persis seperti di bawah (huruf kecil).
Format: .png (disarankan, latar transparan), .webp, .jpg, .svg, atau .gif.
Jika file belum ada, tampil gelembung emoji sebagai cadangan. Hapus file untuk kembali ke cadangan.
Setelah menambah/menghapus file di mode production, jalankan ulang server.

Nama file            Tampil di                                     Ukuran saran
-------------------  --------------------------------------------  -------------
auth-side            Samping formulir Masuk dan Daftar (layar lebar)   600 x 600
home-categories      Samping judul "Mau belajar apa hari ini?"         200 x 200
home-popular         Samping judul "5 Kursus Terpopuler"               200 x 200
home-banner          Banner lebar di beranda tamu (hanya tampil jika ada)  1600 x 400
home-parents         Kotak "Halo Ayah & Bunda"                         400 x 400
empty-courses        Tampilan kosong (belum ada kursus)                300 x 300
empty-certificates   Tampilan kosong (belum ada sertifikat)            300 x 300
footer-art           Footer, sisi kanan                                400 x 400
teacher-hero         Hero dasbor pengajar                              600 x 600
admin-hero           Hero dasbor admin                                 600 x 600
candidate-hero       Hero halaman calon pengajar                       600 x 600

Gambar lain yang sudah ada sebelumnya tetap dipakai:
  public/images/hero-kids.png   ilustrasi anak di hero beranda siswa dan tamu
  public/images/logo.png        logo
  public/images/courses/        gambar per kategori kursus
  public/images/why/            gambar tiga keunggulan di beranda tamu

Gambar sampul kursus dan gambar materi TIDAK ditaruh di sini: unggah lewat form
Kelola Kursus (Gambar kursus) dan Kelola Materi (Gambar materi).
